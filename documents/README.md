# Documents Directory

This directory holds textual documents, unstructured supplier profiles, and replenishment policies intended for future knowledge retrieval and documentation.

## Structure
- `policies/`: Company replenishment guidelines, safety stock regulations, and escalation protocols.
- `suppliers/`: Supplier service-level agreements (SLAs), compliance reports, and contracts.

> **Note**: These files will serve as knowledge sources for the RAG and retrieval modules when implemented in later project phases.
