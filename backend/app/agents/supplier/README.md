# Supplier & Procurement Intelligence Agent (Developer 3)

## Responsibilities
- Track supplier lead times, delivery reliability, pricing tiers, and minimum order quantities (MOQ).
- Assess supplier risk, geopolitical/operational disruptions, and contractual compliance.
- Score and recommend optimal vendors for requested inventory items.

## Associated Files (Recommended Convention)
- Agent Logic: `backend/app/agents/supplier/agent.py`
- Router: `backend/app/routers/supplier.py`
- Models: `backend/app/models/supplier.py`
- Schemas: `backend/app/schemas/supplier.py`
- Tests: `backend/tests/test_supplier.py`
