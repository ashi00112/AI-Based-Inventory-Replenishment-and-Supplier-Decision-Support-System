# Demand & Risk Analysis Agent (Developer 2)

## Responsibilities
- Analyze historical consumption, seasonal trends, and demand patterns.
- Quantify demand uncertainty, volatility, and stockout risks.
- Provide forecasted demand quantities and confidence intervals for upcoming replenishment cycles.

## Associated Files (Recommended Convention)
- Agent Logic: `backend/app/agents/demand/agent.py`
- Router: `backend/app/routers/demand.py`
- Models: `backend/app/models/demand.py`
- Schemas: `backend/app/schemas/demand.py`
- Tests: `backend/tests/test_demand.py`
