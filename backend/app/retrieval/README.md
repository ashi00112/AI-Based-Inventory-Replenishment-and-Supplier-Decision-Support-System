# Retrieval & Document Intelligence

This module will host the shared Retrieval-Augmented Generation (RAG) pipeline when implemented in subsequent phases.

## Future Scope
- Document loaders (ingesting files from `documents/policies/` and `documents/suppliers/`).
- Text chunking & vector embeddings.
- Vector store connectors (e.g. pgvector or standalone vector databases).
- Query retrieval interface consumed by agents requiring contextual grounding.
